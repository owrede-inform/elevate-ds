# ELEVATE Design System

INFORM's design system for building consistent, accessible interfaces across all products.

## Principles

### Provide Shared Value
To ensure that our entire organization benefits from ELEVATE, we only include elements that have shared value across our product teams, allowing the system to stay streamlined and efficient.

### Prioritize Community Input
We actively seek out input from ELEVATE users and synthesize that information into reusable solutions. ELEVATE is a communal system, an evolving formalization of standards refined by the INFORM developer community.

### Invert Control
We structure ELEVATE to put as much control as possible in the hands of the product teams building with the system. This approach aims to balance consistency and flexibility in all the system’s elements.

### Consider System-wide Impact
As stewards of ELEVATE, we ensure that changes made to the system are informed by an understanding of their wider impact. This helps provide solutions that are scalable and sustainable, from the overarching technical architecture, to the finest design details.

### Enable Accessible Experiences
Ensuring that the elements we provide are accessible to everyone is a core facet of the system. We build accessibility-ready components that afford a strong starting point for product teams. We also document best practices for building accessible experiences with ELEVATE.

## What You Get

- **52+ Components** - Buttons, forms, tables, navigation, data display
- **Design Tokens** - Colors, typography, spacing, themes  
- **Patterns** - Common layouts and application shells
- **Accessibility** - WCAG 2.1 AA compliance built-in
- **Theming** - Light, dark, and custom brand support
