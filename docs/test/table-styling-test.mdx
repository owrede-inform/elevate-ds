This page demonstrates that markdown table headers now properly use theme-aware background colors.

**Expected Behavior:**
- **Light Mode**: Table headers should have a light gray background (`#d5d9e1`)
- **Dark Mode**: Table headers should have a darker gray background (`#4d5366`)
- **Text**: Header text should be readable with proper contrast in both modes
- **Borders**: Clean borders with theme-appropriate colors

Test by switching between light and dark modes using the theme toggle in the navbar.
