# Banner

Banners are prominent messages that appear at the top of pages or sections to communicate important information. The ELEVATE Banner component helps designers and developers create consistent, attention-grabbing announcements that inform users without overwhelming the interface.

<TocLinks />

## Overview

### When to Use Banners
- **System announcements**: Maintenance notifications, service updates, new features
- **Promotional content**: Sales, events, new product launches
- **Important alerts**: Security updates, policy changes, urgent information
- **Temporary messaging**: Limited-time offers, seasonal content, campaign information

### When NOT to Use Banners
- **Persistent navigation**: Use navigation components for permanent menu items
- **Form validation**: Use field-level validation messages for form errors
- **Contextual help**: Use tooltips or help text for guidance
- **Status updates**: Use toast notifications for temporary status messages

## Best Practices

### Content Guidelines
- **Keep it concise**: Use clear, brief messaging that users can quickly scan
- **Use hierarchy**: Bold important information and provide clear calls-to-action
- **Include actions**: When appropriate, provide next steps or action buttons
- **Consider timing**: Show banners at relevant moments in the user journey

### Accessibility
- **High contrast**: Ensure banner colors meet WCAG contrast requirements
- **Screen readers**: Include appropriate ARIA labels and roles
- **Keyboard navigation**: Make dismissible banners keyboard accessible
- **Motion sensitivity**: Avoid auto-advancing or animated content

### UX Considerations
- **Limit quantity**: Don't overwhelm users with multiple simultaneous banners
- **Smart timing**: Show contextually relevant messages at appropriate moments
- **Respectful dismissal**: Always allow users to dismiss non-critical banners
- **Mobile optimization**: Ensure banners work well on all screen sizes

## API Reference

### Properties
- `type`: `'info' | 'success' | 'warning' | 'error'` - Banner variant type
- `dismissible`: `boolean` - Whether the banner can be dismissed
- `persistent`: `boolean` - Whether the banner persists until manually dismissed
- `full-width`: `boolean` - Whether the banner spans full container width

### Events
- `elvt-banner-dismiss` - Fired when banner is dismissed
- `elvt-banner-action` - Fired when action button is clicked

### Slots
- `default` - Banner content
- `actions` - Action buttons or links
