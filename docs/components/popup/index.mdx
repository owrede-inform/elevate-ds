# Popup

The Popup component provides a flexible way to display content in a floating panel that appears relative to a trigger element. It's commonly used for tooltips, dropdown menus, contextual information, or small forms that need to appear over existing content.

<TocLinks />

## Overview

### When to Use Popup
- **Tooltips**: Additional information or help text
- **Dropdown menus**: Actions or navigation options
- **Contextual information**: Details that don't warrant a full page
- **Quick forms**: Small input forms or settings panels
- **Preview content**: Quick preview of larger content

### When NOT to Use Popup
- **Major workflows**: Use Dialog or dedicated pages for complex tasks
- **Critical information**: Use notifications for important system messages
- **Large content**: Use dedicated pages for substantial content
- **Mobile primary actions**: Consider full-screen alternatives on mobile

## Basic Example

```jsx
// Basic popup usage - implementation details may vary
<elvt-popup trigger="hover" placement="top">
  <button slot="trigger">Hover me</button>
  <div slot="content">
    This is popup content that appears on hover
  </div>
</elvt-popup>
```

### Common Properties

Based on typical popup component patterns, this component likely supports:

- **`placement`**: Position relative to trigger (top, bottom, left, right, etc.)
- **`trigger`**: How the popup is triggered (click, hover, focus, manual)
- **`offset`**: Distance from the trigger element
- **`arrow`**: Whether to show a pointer arrow
- **`open`**: Controlled open/closed state

### Slots

- **`trigger`**: Element that triggers the popup
- **`content`**: Content displayed in the popup
