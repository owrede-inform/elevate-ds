# Stack

Stack is a fundamental layout component that arranges child elements in vertical or horizontal stacks with consistent spacing, alignment, and distribution options.

## Usage Guidelines

### When to Use
- **Linear layouts** - When elements need to be arranged in a single direction
- **Consistent spacing** - To maintain uniform gaps between elements
- **Responsive design** - For layouts that adapt to different screen sizes
- **Component composition** - As a building block for more complex layouts

### When Not to Use
- **Complex grids** - Use CSS Grid or Flexbox directly for multi-dimensional layouts
- **Overlapping elements** - Use absolute positioning instead
- **Complex responsive behavior** - Consider custom CSS for intricate breakpoint logic

## Component API

### Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `direction` | `'row' \| 'column'` | `'column'` | Stack direction |
| `gap` | `'xs' \| 's' \| 'm' \| 'l' \| 'xl'` | `'m'` | Space between items |
| `alignment` | `'start' \| 'center' \| 'end' \| 'stretch'` | `'stretch'` | Cross-axis alignment |
| `distribution` | `'start' \| 'center' \| 'end' \| 'space-between' \| 'space-around' \| 'space-evenly'` | `'start'` | Main-axis distribution |
| `wrap` | `boolean` | `false` | Allow items to wrap to new lines |
| `inline` | `boolean` | `false` | Display as inline element |

### CSS Custom Properties

| Property | Description |
|----------|-------------|
| `--stack-gap` | Custom gap size overriding the gap property |
| `--stack-padding` | Internal padding of the stack container |

## Gap Sizes

| Size | Value | Use Case |
|------|-------|----------|
| `xs` | 4px | Minimal spacing for tightly related items |
| `s` | 8px | Small spacing for related elements |
| `m` | 16px | Standard spacing for most layouts |
| `l` | 24px | Larger spacing for distinct sections |
| `xl` | 32px | Maximum spacing for major separations |

## Responsive Behavior

Stack automatically adapts to container constraints. For responsive behavior, consider:

- Using wrapping for horizontal stacks with many items
- Switching direction at different breakpoints with CSS
- Adjusting gap sizes for different screen sizes

## Design Guidelines

### Spacing
- Use consistent gap sizes throughout your application
- Choose smaller gaps for related items, larger for distinct sections
- Consider the visual weight of child elements when selecting gaps

### Alignment
- Use `stretch` alignment for form fields and cards
- Use `center` alignment for mixed content types
- Use `start` or `end` alignment for intentional asymmetry

### Direction
- Prefer vertical stacks for most content flows
- Use horizontal stacks for action buttons and navigation
- Consider text direction (LTR/RTL) when using horizontal stacks
