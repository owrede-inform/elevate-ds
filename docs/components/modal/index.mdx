# Modal

Modals are overlay dialogs that focus user attention on specific tasks or information. The ELEVATE Modal component provides accessible, customizable dialogs that maintain context while presenting critical content or actions.

<TocLinks />

## Overview

### When to Use Modals
- **Critical decisions**: Confirmations, destructive actions, important choices
- **Focused tasks**: Forms, workflows that require completion
- **Additional information**: Details, help content, media viewers
- **Alerts and notifications**: Important messages requiring acknowledgment

### When NOT to Use Modals
- **Navigation**: Use routing or inline content for page transitions
- **Complex workflows**: Break long processes into separate pages
- **Frequent interactions**: Use inline editing for common actions
- **Mobile-first content**: Consider drawer or full-page alternatives on small screens

## Best Practices

### Content Guidelines
- **Clear purpose**: Each modal should have a single, clear objective
- **Concise content**: Keep text brief and scannable
- **Action hierarchy**: Make primary actions visually prominent
- **Escape routes**: Always provide a way to cancel or close

### Accessibility
- **Focus management**: Move focus to modal when opened, return when closed
- **Keyboard support**: Support ESC key, tab navigation, and enter/space actions
- **ARIA labels**: Include proper modal, dialog, and button labeling
- **Screen reader support**: Announce modal opening and content changes

### UX Considerations
- **Progressive disclosure**: Use modals for secondary or optional content
- **Mobile adaptation**: Consider full-screen variants on small screens
- **Loading states**: Show progress for async actions within modals
- **Stacking caution**: Avoid opening modals on top of other modals

## API Reference

### Properties
- `open`: `boolean` - Whether the modal is open
- `size`: `'small' | 'medium' | 'large' | 'fullscreen'` - Modal size
- `type`: `'default' | 'alert' | 'confirmation'` - Modal type
- `scrollable`: `boolean` - Whether content is scrollable
- `no-dismiss`: `boolean` - Prevents dismissal by clicking outside or ESC
- `no-header`: `boolean` - Hides the header section
- `no-footer`: `boolean` - Hides the footer section

### Events
- `elvt-modal-open` - Fired when modal opens
- `elvt-modal-close` - Fired when modal closes
- `elvt-modal-dismiss` - Fired when modal is dismissed via ESC or backdrop
- `elvt-modal-action` - Fired when action button is clicked

### Slots
- `header` - Modal header content
- `default` - Main modal content
- `footer` - Modal footer with actions

### Methods
- `open()` - Programmatically open the modal
- `close()` - Programmatically close the modal
