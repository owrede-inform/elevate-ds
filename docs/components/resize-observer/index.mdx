# Resize Observer

The Resize Observer component provides a declarative way to observe element size changes and react to dimension modifications, enabling responsive behavior and dynamic layouts.

## Usage Guidelines

### When to Use
- **Responsive components** - Building components that adapt to container size changes
- **Dynamic layouts** - Creating layouts that respond to content or viewport changes
- **Performance optimization** - Optimizing rendering based on available space
- **Container queries** - Implementing container-based responsive design
- **Chart and visualization** - Updating graphics when containers resize

### When Not to Use
- **Viewport changes only** - Use media queries for viewport-based responsive design
- **Static layouts** - Unnecessary for fixed-size content
- **Performance-critical code** - Frequent resize observations can impact performance

## Component API

### Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `target` | `string \| Element` | - | Target element or CSS selector to observe |
| `box` | `'content-box' \| 'border-box' \| 'device-pixel-content-box'` | `'content-box'` | Which box model to observe |
| `disabled` | `boolean` | `false` | Disable the observer |

### Events

| Event | Description |
|-------|-------------|
| `elvt-resize` | Fired when the observed element's size changes |

### Event Details

The `elvt-resize` event includes detailed size information:

```typescript
interface ResizeEventDetail {
  contentRect: DOMRectReadOnly;
  borderBoxSize: ResizeObserverSize[];
  contentBoxSize: ResizeObserverSize[];
  devicePixelContentBoxSize?: ResizeObserverSize[];
  target: Element;
}
```

## Box Models

### Content Box (Default)
- Measures the content area excluding padding and border
- Most common for layout calculations
- Consistent with CSS `box-sizing: content-box`

### Border Box
- Includes padding and border in measurements
- Useful when working with `box-sizing: border-box`
- Matches element's total rendered size

### Device Pixel Content Box
- Provides device pixel measurements
- Useful for high-DPI displays and canvas elements
- May not be available in all browsers

## Event Handling

### JavaScript Event Listener

```javascript
// Listen for resize events
document.addEventListener('elvt-resize', (event) => {
  const { 
    contentRect, 
    borderBoxSize, 
    contentBoxSize, 
    target 
  } = event.detail;
  
  // Access size information
  const width = contentRect.width;
  const height = contentRect.height;
  
  // Respond to size changes
  updateLayoutForSize(target, width, height);
});
```

### Debouncing Resize Events

```javascript
let resizeTimeout;

document.addEventListener('elvt-resize', (event) => {
  clearTimeout(resizeTimeout);
  
  resizeTimeout = setTimeout(() => {
    // Perform expensive operations after resize settles
    updateExpensiveLayout(event.detail);
  }, 100);
});
```

## Performance Considerations

### Optimization Strategies
- **Throttling**: Limit the frequency of expensive operations
- **Debouncing**: Wait for resize to settle before expensive calculations
- **Conditional updates**: Only update when size changes significantly
- **Efficient selectors**: Use specific target selectors

### Memory Management
- Disable observers when components are destroyed
- Avoid keeping references to observed elements
- Clean up event listeners when no longer needed

- Grid systems that adapt to container size

- Charts that redraw when container size changes
