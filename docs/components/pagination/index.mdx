# Pagination

Pagination breaks large datasets into smaller, manageable chunks, helping users navigate efficiently through content. The ELEVATE Pagination component provides accessible navigation patterns that maintain context and performance.

<TocLinks />

## Overview

### When to Use Pagination
- **Large datasets**: Tables, lists, search results with many items
- **Performance optimization**: Reducing load times by limiting displayed items
- **User experience**: Making content consumption more manageable
- **Sequential content**: Articles, galleries, multi-step processes

### When NOT to Use Pagination
- **Small datasets**: Lists with fewer than 25-50 items
- **Infinite scroll contexts**: Social feeds, continuous browsing experiences
- **Single-page content**: All content fits comfortably on one page
- **Real-time data**: Live feeds where pagination would interrupt updates

## Best Practices

### Content Guidelines
- **Clear labeling**: Use descriptive text for navigation controls
- **Consistent numbering**: Start page numbers from 1, not 0
- **Helpful information**: Show total items, current range, and context
- **Reasonable defaults**: Use sensible page sizes (25-50 items typically)

### Accessibility
- **Keyboard navigation**: Support tab navigation and enter/space activation
- **Screen reader support**: Include ARIA labels and page context
- **Focus management**: Maintain logical focus order through controls
- **High contrast**: Ensure controls are visible with sufficient contrast

### UX Considerations
- **Performance**: Load pages efficiently without blocking interactions
- **URL integration**: Update URLs to support bookmarking and back navigation
- **Mobile optimization**: Use appropriate sizing and touch targets
- **Context preservation**: Maintain filters, sorting, and search state

## API Reference

### Properties
- `current-page`: `number` - Currently active page (1-indexed)
- `total-pages`: `number` - Total number of pages
- `total-items`: `number` - Total number of items across all pages
- `page-size`: `number` - Number of items per page
- `type`: `'default' | 'simple'` - Pagination type
- `size`: `'compact' | 'default' | 'large'` - Control sizing
- `max-visible`: `number` - Maximum visible page numbers
- `show-first-last`: `boolean` - Show first/last page buttons
- `show-info`: `boolean` - Show pagination information
- `show-page-size`: `boolean` - Show page size selector
- `show-quick-jump`: `boolean` - Show page jump input
- `page-size-options`: `number[]` - Available page size options
- `info-template`: `string` - Template for pagination info text
- `loading`: `boolean` - Show loading state
- `disabled`: `boolean` - Disable all controls

### Events
- `elvt-pagination-change` - Fired when page changes
- `elvt-pagination-size-change` - Fired when page size changes
- `elvt-pagination-jump` - Fired when quick jump is used

### Slots
- `info` - Custom pagination information display
- `controls` - Custom pagination controls

### Methods
- `goToPage(page)` - Navigate to specific page
- `nextPage()` - Go to next page
- `previousPage()` - Go to previous page
- `firstPage()` - Go to first page
- `lastPage()` - Go to last page
