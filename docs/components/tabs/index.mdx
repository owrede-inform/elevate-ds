# Tabs

Tabs provide a way to organize related content into separate panels, allowing users to switch between different views efficiently. The ELEVATE Tabs component offers accessible navigation patterns that maintain context while presenting multiple content sections.

<TocLinks />

## Overview

### When to Use Tabs
- **Related content sections**: Settings panels, data views, content categories
- **Space efficiency**: Reducing vertical scrolling by organizing content
- **Contextual organization**: Grouping similar functionality or information
- **Navigation within sections**: Moving between different aspects of the same topic

### When NOT to Use Tabs
- **Sequential processes**: Use stepper or multi-page flows for workflows
- **Unrelated content**: Use separate pages for distinct topics
- **Single content section**: No need for tabs with only one content area
- **Critical comparisons**: When users need to see multiple sections simultaneously

## Best Practices

### Content Guidelines
- **Clear labels**: Use concise, descriptive tab names
- **Logical grouping**: Organize related content together
- **Consistent content**: Maintain similar content structure across tabs
- **Appropriate length**: Keep tab labels short but meaningful

### Accessibility
- **Keyboard navigation**: Support arrow keys and tab navigation
- **Screen reader support**: Include proper ARIA labels and roles
- **Focus management**: Maintain clear focus indicators
- **High contrast**: Ensure sufficient contrast for active/inactive states

### UX Considerations
- **Reasonable number**: Limit tabs to 5-7 for optimal usability
- **Mobile adaptation**: Consider accordion or dropdown alternatives
- **Content relationships**: Ensure tab content is truly related
- **State persistence**: Remember selected tab across sessions when appropriate

## API Reference

### Tabs Properties
- `active-tab`: `string` - ID of currently active tab
- `orientation`: `'horizontal' | 'vertical'` - Tab layout direction
- `variant`: `'default' | 'bordered' | 'pills'` - Visual style variant
- `size`: `'small' | 'medium' | 'large'` - Tab sizing
- `scrollable`: `boolean` - Enable horizontal scrolling for overflow
- `closable`: `boolean` - Allow tabs to be closed

### Tab Properties
- `tab-id`: `string` - Unique identifier for the tab
- `active`: `boolean` - Whether this tab is currently active
- `disabled`: `boolean` - Whether the tab is disabled
- `closable`: `boolean` - Whether this specific tab can be closed

### Events
- `elvt-tab-change` - Fired when active tab changes
- `elvt-tab-close` - Fired when a tab is closed
- `elvt-tab-add` - Fired when a new tab is added

### Slots
- `default` - Tab content within tab panels
- `tab-content` - Custom content for individual tabs

### Methods
- `activateTab(tabId)` - Activate specific tab
- `closeTab(tabId)` - Close specific tab
- `addTab(tabData)` - Add new tab dynamically
