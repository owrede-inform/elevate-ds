# Tab Panel

Tab panels contain the content associated with each tab in a tab group. They provide the content area that displays when users select different tabs.

## Usage Guidelines

### When to Use
- **Tabbed interfaces** - As content containers within tab groups
- **Conditional content** - To show/hide content based on tab selection
- **Accessible content** - When proper ARIA relationships are needed
- **Lazy loading** - For content that should only render when visible

### When Not to Use
- **Standalone content** - Use regular containers for non-tabbed content
- **Always visible content** - Use standard layout components instead
- **Simple toggles** - Consider switches or buttons for simple show/hide

## Component API

### Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `name` | `string` | - | Unique identifier that matches the tab's panel attribute |
| `active` | `boolean` | `false` | Whether this panel is currently active |
| `lazy` | `boolean` | `false` | Whether to render content only when active |

### CSS Custom Properties

| Property | Description |
|----------|-------------|
| `--tab-panel-padding` | Internal padding of the panel |
| `--tab-panel-border` | Border styling for the panel |
| `--tab-panel-background` | Background color of the panel |

## Accessibility

### ARIA Attributes
- `role="tabpanel"` - Identifies the element as a tab panel
- `aria-labelledby` - References the associated tab element
- `tabindex="0"` - When active, `-1` when inactive

### Keyboard Navigation
- **Tab** - Moves focus to the active panel (if focusable content exists)
- **Shift + Tab** - Moves focus back to the tab navigation

### Screen Reader Support
- Panel content is announced when tabs are activated
- Lazy panels announce loading states appropriately
- Content structure (headings, etc.) is preserved for navigation

## Design Guidelines

### Content Organization
- Start each panel with a clear heading
- Use consistent padding across all panels
- Organize content logically within each panel

### Visual Hierarchy
- Maintain consistent typography scale
- Use appropriate spacing between content sections
- Consider content length differences between panels

### Loading States
- Use skeleton placeholders for lazy-loaded content
- Provide loading indicators for dynamic content
- Ensure smooth transitions between panels
