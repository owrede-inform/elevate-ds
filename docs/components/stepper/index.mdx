# Stepper

Steppers display progress through a sequence of logical and numbered steps, helping users understand where they are in a multi-step process. The ELEVATE Stepper component provides clear navigation and status indication for complex workflows.

<TocLinks />

## Overview

### When to Use Steppers
- **Multi-step forms**: Registration, checkout, onboarding processes
- **Sequential workflows**: Setup wizards, guided tours, configuration processes
- **Progress tracking**: Show completion status and remaining steps
- **Linear processes**: When steps must be completed in a specific order

### When NOT to Use Steppers
- **Non-linear processes**: When users can complete steps in any order
- **Simple forms**: Single-page forms that don't require step division
- **Parallel tasks**: Multiple independent actions that aren't sequential
- **Continuous processes**: Workflows without discrete completion points

## Best Practices

### Content Guidelines
- **Clear labels**: Use concise, descriptive step names
- **Helpful descriptions**: Provide context about what each step involves
- **Consistent language**: Use similar tone and terminology throughout
- **Progress indicators**: Show users how many steps remain

### Accessibility
- **Keyboard navigation**: Support tab navigation and arrow key movement
- **Screen reader support**: Include step status and progress announcements
- **Focus management**: Maintain logical focus order through steps
- **High contrast**: Ensure step indicators are clearly visible

### UX Considerations
- **Linear flow**: Ensure steps follow logical progression
- **Error handling**: Clearly indicate and explain validation errors
- **Save progress**: Consider saving progress for long multi-step forms
- **Mobile optimization**: Use vertical layout or adapt for smaller screens

## API Reference

### Stepper Properties
- `current-step`: `number` - Currently active step (1-indexed)
- `orientation`: `'horizontal' | 'vertical'` - Layout direction
- `size`: `'default' | 'compact'` - Size variant
- `show-numbers`: `boolean` - Display step numbers
- `clickable`: `boolean` - Allow clicking on completed steps
- `show-connector`: `boolean` - Show lines connecting steps

### Step Properties
- `status`: `'pending' | 'active' | 'completed' | 'error' | 'disabled'` - Step state
- `clickable`: `boolean` - Override stepper clickable setting
- `optional`: `boolean` - Mark step as optional

### Events
- `elvt-stepper-change` - Fired when step changes
- `elvt-stepper-step-click` - Fired when step is clicked
- `elvt-stepper-complete` - Fired when all steps are completed

### Slots
- `label` - Step title
- `description` - Step description
- `icon` - Custom step icon
- `content` - Step content area

### Methods
- `goToStep(stepNumber)` - Navigate to specific step
- `nextStep()` - Move to next step
- `previousStep()` - Move to previous step
- `reset()` - Reset to first step
