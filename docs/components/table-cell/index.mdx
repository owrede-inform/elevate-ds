# Table Cell

Table cells are the basic content containers within table rows, providing flexible content display and formatting options for tabular data.

## Usage Guidelines

### When to Use
- **Tabular data** - As content containers within table rows
- **Data formatting** - When specific cell formatting is needed
- **Interactive content** - For cells containing buttons, links, or form elements
- **Custom styling** - When individual cell styling is required

### When Not to Use
- **Non-tabular content** - Use regular containers for non-table layouts
- **Simple lists** - Consider list components for basic data display

## Component API

### Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `header` | `boolean` | `false` | Renders as table header cell (th) |
| `align` | `'start' \| 'center' \| 'end'` | `'start'` | Text alignment |
| `colspan` | `number` | `1` | Number of columns to span |
| `rowspan` | `number` | `1` | Number of rows to span |
| `sortable` | `boolean` | `false` | Whether column is sortable (header cells) |
| `sorted` | `'asc' \| 'desc' \| 'none'` | `'none'` | Current sort direction |

### Events

| Event | Description |
|-------|-------------|
| `elvt-sort` | Fired when sortable header is clicked |

### CSS Custom Properties

| Property | Description |
|----------|-------------|
| `--table-cell-padding` | Cell padding |
| `--table-cell-border` | Cell border styling |
| `--table-cell-background` | Cell background color |
