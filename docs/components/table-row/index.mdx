# Table Row

Table rows group table cells together and provide row-level functionality such as selection, hover states, and semantic organization of tabular data.

## Usage Guidelines

### When to Use
- **Data organization** - To group related cells into logical rows
- **Row interactions** - When rows need selection, hover, or click behavior
- **Semantic structure** - To maintain proper table accessibility
- **Row styling** - When specific row styling or states are needed

### When Not to Use
- **Non-tabular content** - Use other layout components for non-table data
- **Single row displays** - Consider cards or lists for standalone content

## Component API

### Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `selected` | `boolean` | `false` | Whether the row is selected |
| `disabled` | `boolean` | `false` | Whether the row is disabled |
| `clickable` | `boolean` | `false` | Whether the row responds to clicks |
| `variant` | `'default' \| 'highlighted' \| 'danger'` | `'default'` | Row visual variant |
| `index` | `number` | - | Row index for programmatic reference |

### Events

| Event | Description |
|-------|-------------|
| `elvt-row-click` | Fired when a clickable row is clicked |
| `elvt-row-select` | Fired when row selection changes |

### CSS Custom Properties

| Property | Description |
|----------|-------------|
| `--table-row-background` | Background color of the row |
| `--table-row-border` | Border styling for the row |
| `--table-row-hover-background` | Background color on hover |
| `--table-row-selected-background` | Background color when selected |

## Row States

### Default State
- Standard row appearance
- Subtle hover effect when clickable
- No special visual treatment

### Selected State
- Highlighted background color
- Indicates user selection
- Often used with checkboxes

### Disabled State
- Reduced opacity
- No hover or click interactions
- Indicates unavailable content

### Variants
- **Default**: Standard appearance for regular content
- **Highlighted**: Emphasized appearance for important rows
- **Danger**: Warning appearance for error or critical states

## Accessibility

### Semantic Structure
- Uses proper `tr` element for table rows
- Maintains semantic relationship with table cells
- Supports screen reader navigation

### Keyboard Navigation
- **Tab** - Navigate between interactive elements within rows
- **Enter/Space** - Activate clickable rows
- **Arrow Keys** - Navigate between table cells

### Screen Reader Support
- Row selection states are announced
- Clickable rows include appropriate roles
- Cell content relationships are preserved

### Focus Management
- Visual focus indicators on interactive rows
- Logical tab order within row content
- Skip navigation support for large tables

## Design Guidelines

### Visual Hierarchy
- Use consistent row heights for scanability
- Apply subtle hover states for interactive rows
- Maintain clear visual separation between rows

### Selection Patterns
- Provide clear visual feedback for selections
- Use consistent selection mechanisms (checkboxes)
- Support both single and multi-selection patterns

### Content Organization
- Align related data consistently across rows
- Use consistent formatting within columns
- Group related actions in dedicated columns
