# Loading

Loading indicators inform users that the system is processing their request and provide reassurance during wait times. The ELEVATE Loading component offers various patterns to match different loading scenarios and user experiences.

<TocLinks />

## Overview

### When to Use Loading Indicators
- **Data fetching**: API calls, database queries, search results
- **Form submissions**: Processing form data, validation, saving
- **Page transitions**: Route changes, dynamic content loading
- **File operations**: Uploads, downloads, file processing

### When NOT to Use Loading Indicators
- **Instant operations**: Actions that complete in under 200ms
- **Background tasks**: Operations that don't affect current user workflow
- **Progressive enhancement**: Content that loads incrementally without blocking interaction
- **Error states**: Use error messages instead of loading indicators for failed operations

## Best Practices

### Performance Guidelines
- **Show immediately**: Display loading indicators within 100ms of user action
- **Provide context**: Include descriptive text explaining what's loading
- **Set expectations**: Use progress bars when completion time is known
- **Avoid nesting**: Don't stack multiple loading states simultaneously

### Accessibility
- **ARIA labels**: Include appropriate loading announcements for screen readers
- **Focus management**: Handle keyboard focus during loading states
- **Reduced motion**: Respect user preferences for reduced motion
- **Timeout handling**: Provide error states for failed loading operations

### UX Considerations
- **Perceived performance**: Use skeleton screens to maintain layout
- **Progressive disclosure**: Show partial content as it becomes available
- **Graceful degradation**: Handle slow connections with appropriate fallbacks
- **Loading hierarchy**: Prioritize critical content loading over secondary features

## API Reference

### Properties
- `type`: `'spinner' | 'progress' | 'skeleton' | 'dots'` - Loading indicator type
- `size`: `'small' | 'medium' | 'large'` - Size variant
- `progress`: `number` - Progress percentage (0-100) for progress type
- `overlay`: `boolean` - Whether to show as overlay
- `inline`: `boolean` - Whether to display inline with text
- `variant`: `'text' | 'circular' | 'rectangular'` - Skeleton variant
- `lines`: `number` - Number of skeleton lines for text variant

### Events
- `elvt-loading-complete` - Fired when loading completes
- `elvt-loading-timeout` - Fired when loading times out
- `elvt-loading-error` - Fired when loading fails

### Slots
- `default` - Content to show with loading indicator
