# Tag

Tags provide a flexible way to categorize, label, and organize content. The ELEVATE Tag component offers various visual styles and interactive patterns to help users understand content relationships and filter information effectively.

<TocLinks />

## Overview

### When to Use Tags
- **Content categorization**: Blog posts, articles, documentation sections
- **Metadata display**: Status indicators, attributes, properties
- **Filtering interfaces**: Search results, product catalogs, data tables
- **User-generated content**: Social tags, bookmarks, organizational labels

### When NOT to Use Tags
- **Navigation**: Use breadcrumbs or navigation menus for site structure
- **Primary actions**: Use buttons for clickable actions
- **Form inputs**: Use appropriate form controls for data entry
- **Status badges**: Use badges for system status and notifications

## Best Practices

### Content Guidelines
- **Concise labels**: Use short, descriptive text that's easy to scan
- **Consistent terminology**: Maintain consistent naming across similar tags
- **Meaningful categories**: Choose categories that help users understand content
- **Appropriate quantity**: Limit tags per item to avoid overwhelming users

### Accessibility
- **Keyboard support**: Ensure clickable and removable tags work with keyboard navigation
- **Screen reader support**: Include appropriate ARIA labels and role attributes
- **Focus indicators**: Provide clear visual focus states for interactive tags
- **Color independence**: Don't rely solely on color to convey meaning

### UX Considerations
- **Logical grouping**: Group related tags together for better organization
- **Visual hierarchy**: Use size and color consistently to establish importance
- **Clear interactions**: Make clickable and removable actions obvious to users
- **Responsive behavior**: Ensure tags work well on mobile and desktop devices

## API Reference

### Tag Properties
- `variant`: `'default' | 'primary' | 'secondary' | 'success' | 'warning' | 'danger' | 'info'` - Visual style variant
- `size`: `'small' | 'medium' | 'large'` - Tag sizing
- `shape`: `'default' | 'pill'` - Border radius style
- `outlined`: `boolean` - Use outline style instead of filled
- `clickable`: `boolean` - Enable click interaction
- `removable`: `boolean` - Show remove button
- `active`: `boolean` - Show active/selected state
- `disabled`: `boolean` - Disable all interactions

### Tag Group Properties
- `label`: `string` - Group label text
- `max-visible`: `number` - Maximum tags to show before overflow
- `collapsible`: `boolean` - Allow expanding/collapsing overflow tags
- `spacing`: `'compact' | 'normal' | 'comfortable'` - Spacing between tags

### Events
- `elvt-tag-click` - Fired when tag is clicked (clickable tags only)
- `elvt-tag-remove` - Fired when tag is removed
- `elvt-tag-activate` - Fired when tag becomes active

### Slots
- `default` - Tag content text
- `start` - Content before the text (icons, indicators)
- `end` - Content after the text (badges, counts)

### Methods
- `setActive(active)` - Programmatically set active state
- `remove()` - Programmatically remove tag
- `focus()` - Focus the tag element
