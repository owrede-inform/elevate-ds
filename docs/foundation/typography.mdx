# ELEVATE Typography System

Typography is the foundation of clear communication and visual hierarchy. ELEVATE's TypeAlias token system provides semantic typography tokens that ensure consistency across all interfaces while maintaining flexibility for various content needs.

## Typography Philosophy

### Design Principles
- **Semantic Meaning** - TypeAlias tokens represent purpose, not just size
- **Hierarchical Clarity** - Clear information hierarchy through systematic scaling
- **Content-First** - Body text optimized for readability and comprehension
- **Future-Proof** - Token-based system that adapts to design evolution

### "Eat Your Own Dogfood"
This documentation site demonstrates ELEVATE typography in action. Every heading, paragraph, and text element uses ELEVATE TypeAlias tokens, proving the system's effectiveness in real-world applications.

## ELEVATE TypeAlias Token Structure

### Token Naming Convention
```
--elvt-type-alias-{emphasis}-{purpose}-{size}-{property}
```

**Components:**
- **Emphasis**: `default`, `emphasized`, `important`, `strong`
- **Purpose**: `content`, `caption`, `label`, `section`, `headline`, `display`
- **Size**: `s`, `m`, `l`, `xl` (medium is the standard)
- **Property**: `font-family`, `font-size`, `font-weight`, `line-height`

## Typography Best Practices

### 1. Use Semantic Tokens

**✅ Do:** Choose tokens based on content purpose
```css
/* Article title */
.article-title {
  font-size: var(--elvt-type-alias-default-display-m-font-size);
}

/* Section header */
.section-header {
  font-size: var(--elvt-type-alias-default-headline-m-font-size);
}

/* Body content */
.body-text {
  font-size: var(--elvt-type-alias-default-content-m-font-size);
}
```

**❌ Don't:** Choose tokens based only on visual size
```css
/* Wrong - choosing by size not purpose */
.form-label {
  font-size: var(--elvt-type-alias-default-display-m-font-size); /* Too large! */
}
```

### 2. Maintain Consistent Hierarchy

- **Display** → Hero/banner content
- **Headline** → Major section divisions  
- **Section** → Subsection organization
- **Label** → UI labels and form elements
- **Content** → Body text and paragraphs
- **Caption** → Supporting information and metadata

### 3. Typography Token Combinations

Combine size, weight, and line-height tokens for complete typography definitions:

```css
.component-title {
  font-family: var(--elvt-type-alias-default-section-m-font-family);
  font-size: var(--elvt-type-alias-default-section-m-font-size);
  font-weight: var(--elvt-type-alias-important-section-m-font-weight);
  line-height: var(--elvt-type-alias-default-section-m-line-height);
}
```

## Size Variations

### Beyond Medium (`-m`)

ELEVATE provides multiple size variants for each semantic token:

- **Small (`-s`)** - Compact layouts, mobile interfaces
- **Medium (`-m`)** - Standard desktop interfaces (default)
- **Large (`-l`)** - Spacious layouts, large screens
- **Extra Large (`-xl`)** - Hero sections, marketing content

```css
/* Responsive section headers */
.section-title {
  font-size: var(--elvt-type-alias-default-section-s-font-size); /* Mobile */
}

@media (min-width: 768px) {
  .section-title {
    font-size: var(--elvt-type-alias-default-section-m-font-size); /* Desktop */
  }
}

@media (min-width: 1200px) {
  .section-title {
    font-size: var(--elvt-type-alias-default-section-l-font-size); /* Large */
  }
}
```

## Accessibility Considerations

### WCAG Compliance

ELEVATE typography tokens are designed with accessibility in mind:

- **Minimum Sizes** - All tokens meet WCAG minimum size requirements
- **Contrast Ratios** - When combined with ELEVATE color tokens, achieve minimum 4.5:1 contrast
- **Line Height** - Built-in line heights optimize readability for each token size
- **Font Choice** - Inter font provides excellent screen readability

### Implementation Guidelines

```css
/* Accessible text combinations */
.accessible-text {
  font-size: var(--elvt-type-alias-default-content-m-font-size);
  line-height: var(--elvt-type-alias-default-content-m-line-height);
  color: var(--elvt-alias-content-text-default);
}

/* High contrast for important content */
.important-text {
  font-size: var(--elvt-type-alias-emphasized-content-m-font-size);
  font-weight: var(--elvt-type-alias-important-content-m-font-weight);
  color: var(--elvt-alias-content-text-primary);
}
```

## Future-Proofing

### Token Evolution

The TypeAlias token system is designed to evolve with ELEVATE:

1. **Semantic Stability** - Token purposes remain consistent
2. **Value Updates** - Underlying sizes and weights can be refined
3. **New Variants** - Additional emphasis levels or sizes can be added
4. **Framework Independence** - Tokens work across different UI frameworks

### Migration Strategy

When ELEVATE typography tokens evolve:

```css
/* Current implementation */
.text-style {
  font-size: var(--elvt-type-alias-default-content-m-font-size, 1rem);
}

/* Fallback values ensure graceful degradation */
/* Token updates automatically propagate to all components */
```
