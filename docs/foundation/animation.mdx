# Animation

Thoughtful animation enhances user experience by providing feedback, guiding attention, and creating delightful interactions. ELEVATE's animation system balances performance, accessibility, and purposeful motion.

## Animation Principles

### Purpose-Driven Motion
Every animation should serve a clear function. Use motion only when it adds meaning to the interaction—whether drawing attention to changes, explaining relationships between elements, or providing context during transitions.

(EXAMPLE)

### Timing and Responsiveness
Animations should feel immediate and responsive to user actions. Trigger animations within 0.1 seconds of user interaction, and keep durations brief to avoid interrupting task flow.

- **Direct interactions**: Fast transitions (100-200ms)
- **Indirect triggers**: Slower transitions (200-300ms)
- **Complex sequences**: Break into smaller, staged animations

(EXAMPLE)

### Attention Management
Motion automatically captures visual attention, especially in peripheral vision. Use this power responsibly—faster, self-propelled movements attract more attention and should be reserved for truly important notifications.

(EXAMPLE)

## Pulse Animation

Pulse animations create rhythmic emphasis for notifications, loading states, or highlighting interactive elements. The gentle scaling effect draws attention without being disruptive.

**Use Cases:**
- New message indicators
- Loading states
- Call-to-action emphasis
- Heartbeat monitoring displays

**Technical Specifications:**
- Duration: 1-2 seconds per pulse
- Scale range: 1.0 to 1.05
- Easing: ease-in-out
- Repetition: 2-3 cycles maximum

(EXAMPLE)

## Blending Animation

Blending animations handle smooth transitions between states, typically using opacity and color changes. These subtle transitions maintain visual continuity while indicating state changes.

**Use Cases:**
- Hover state transitions
- Form validation feedback
- Theme switching
- Content updates

**Technical Specifications:**
- Duration: 150-250ms
- Properties: opacity, background-color, border-color
- Easing: cubic-bezier for natural motion
- Trigger: immediate on state change

(EXAMPLE)

## Moving Animation

Moving animations guide users through spatial relationships and workflow transitions. These animations help users understand where content comes from and where it goes.

**Use Cases:**
- Navigation transitions
- Modal entry/exit
- Drawer sliding
- Card rearrangement
- Page transitions

**Technical Specifications:**
- Duration: 200-400ms depending on distance
- Properties: transform (translate, scale)
- Easing: ease-out for entrances, ease-in for exits
- Path: straight lines or gentle curves

(EXAMPLE)

## Accessibility Considerations

### Reduced Motion Preferences
Always respect user preferences for reduced motion. Provide CSS media queries to disable or minimize animations for users who prefer less visual stimulation.

```css
@media (prefers-reduced-motion: reduce) {
  /* Disable or reduce animations */
  .animated-element {
    animation: none;
  }
}
```

### Performance Guidelines
- Use CSS transforms and opacity for the smoothest animations
- Avoid animating layout properties (width, height, padding)
- Test animations on lower-powered devices
- Keep simultaneous animations to a minimum

### Focus and Navigation
Ensure animations don't interfere with keyboard navigation or screen readers. Provide alternative text descriptions for complex animated sequences when necessary.
